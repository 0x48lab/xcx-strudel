ブロックじてん

この ブロック、どういう ときに つかうの? どうやって つかうの? を しらべよう。

トップ チュートリアル ブロックじてん リズム図鑑 新規プロジェクト

この じてんは、パレットの 上から じゅんばんに、ブロック 1つ 1つの つかいかたを しょうかいするよ。ブロックの 絵の とおりに 組んで、ためしてみよう。「れいを ぜんぶ 開く」で、じてんの れいが ぜんぶ 入った 作品が 開くよ。

ブロックや ▼ は 日本語や カタカナで 書いてあるけど、ほとんどが Strudel の 関数に なっている(「はやくする」は fast、「アルペジオ」は arp)。見出しの となりの 名前が Strudel の 名前で、「なまえと れきし」を ひらくと、どこから 来た 名前かが わかるよ。

「トラック [ ] で鳴らす」の 中の ブロックは、上から じゅんばんに Strudel の .fast(4) のような 1だんずつに なるよ。

Strudel の 名前は どこから 来たの?

Strudel の もとに なったのは、TidalCycles(タイダルサイクルズ)という 音楽の プログラミング言語だよ。イギリスの Alex McLean(アレックス・マクリーン)さんが 2009年ごろに Haskell という 言語で つくり、その場で コードを 書きかえながら 演奏する「ライブコーディング」の 道具として 世界中で つかわれてきた。

2022年、Felix Roos(フェリックス・ロース)さんと Alex McLean さんが、TidalCycles の しくみを JavaScript に うつして、ブラウザだけで 鳴らせるように した。これが Strudel だよ。だから fast rev every jux などの 名前の 多くは、TidalCycles から 受けついだ ものなんだ。「サイクル」で 時間を 数える 考えかたも、TidalCycles の 名前の とおりだね。

音の 名前(bd lpf sawtooth など)は、もっと 古く、ドラムマシンや シンセサイザーの れきしから 来ているよ。

トラックと テンポ

トラック [ ] で鳴らす Strudel: $: ビギナー

何が 起きる?

中に 積んだ ブロックで パターンを 作って、名前の ついた トラックで 鳴らしつづける。同じ 名前で もう一度 鳴らすと、つぎの サイクルから 入れかわる。名前を かえると、べつの トラックとして 重なるよ。

ためしてみよう

ドン ドン ドン ドン と キックが 鳴りつづける。

よく つかう 場面

  • ドラム・ベース・メロディを トラックに 分けて、1つずつ 止めたり かえたり する
  • キーを おしたら 同じ トラックを べつの パターンで 鳴らして、曲を 切りかえる

Strudel では

s("bd").fast(4)
なまえと れきし

中の ブロックは 上から じゅんばんに、Strudel の .fast(4) のような 1だんずつに なる。トラック 1本が Strudel の $: の 1行に あたるよ。

トラック [ ] を止める Strudel: hush ビギナー

何が 起きる?

名前の トラックを 止める。ほかの トラックは 鳴りつづけるよ。

ためしてみよう

スペースキーを おすと、「ドラム」トラックだけ 止まる。

よく つかう 場面

  • ドラムを 止めて「ブレイク」を つくる(リズム図鑑)

Strudel では

$: s("bd*4").hush()
なまえと れきし

Strudel では、その 行を 消すか、行の さいごに .hush()(だまらせる)を つける。

すべてのトラックを止める Strudel: hush ビギナー

何が 起きる?

ぜんぶの トラックを 止めて、わすれる。赤い ボタン(止める)は 音を 止める だけで、トラックの 中身は おぼえている(「全部のトラックのStrudelコード」に のこる)。このブロックは 中身も 消すよ。

ためしてみよう

0 キーを おすと、音が ぜんぶ 止まる。

よく つかう 場面

  • 曲の おわりや、やりなおす ときに つかう

Strudel では

hush()
なまえと れきし

hush は 英語で「しーっ、静かに」。strudel.cc では Ctrl + . でも 止まるよ。

テンポを [ ] BPMにする Strudel: setcpm ビギナー

何が 起きる?

テンポ(1分間に 何拍か)を きめる。ふつうは 120 くらい。ヒップホップは 90 くらい、ドラムンベースは 170 くらい だよ。

ためしてみよう

緑の旗を おすと、テンポが 90 に なって、ゆっくりに なる。

よく つかう 場面

  • ジャンルに あわせて テンポを えらぶ(リズム図鑑に ジャンルごとの BPM が あるよ)

Strudel では

setcpm(90/4)
なまえと れきし

BPM = beats per minute(1分間の 拍の 数)。Strudel は サイクルで 数えるので、1サイクルが 4拍なら setcpm(90/4)(1分間に 22.5 サイクル)と 書くよ。

サイクルの拍の数を [ ] にする Strudel: setcpm ノーマル

何が 起きる?

1サイクルを 何拍に するかを きめる。ふつうは 4拍。3 に すると ワルツの ような 3拍子に なるよ。

ためしてみよう

ズン チャッ チャッ の 3拍子に なる。

よく つかう 場面

  • ワルツや 6/8拍子の 曲を つくる
  • 「拍がきたとき」で 動く 回数を かえる

Strudel では

setcpm(120/3)
$: s("bd sd sd")
なまえと れきし

テンポ(BPM)は かえずに、1サイクルの 長さが かわる。「拍がきたとき」と「拍」も この 数に あわせて 動くよ。

音を えらぶ

音 [ ] Strudel: s ビギナー

何が 起きる?

鳴らす 音の 種類を きめる。ビギナーでは ▼ で えらび、ノーマルからは 文字で ミニ記法を 書ける。トラックの 一番上なら 音を きめ、下に 置くと 音色を かえるよ(.s())。

ためしてみよう

ドン チッ タン チッ と 鳴る。

よく つかう 場面

  • ドラムの リズムを 書く(リズム図鑑)
  • 「音の高さ」の 下に 置いて、ピアノや シンセの 音に する

Strudel では

s("bd hh sd hh")

えらべる 名前

名前何が 起きる?
bd sd hh oh cp rim lt mt ht crドラムの 音の 名前。bd = バスドラム、sd = スネア、hh = ハイハット、oh = オープンハイハット、cp = クラップ(手拍子)、rim = リム、lt / mt / ht = 低い / 中くらい / 高い タム、cr = クラッシュシンバル。
s("bd hh sd hh")
sbdシンセサイザーで つくった キック(synth bass drum)。録音した 音ではなく、計算で 鳴らしているよ。
s("sbd!4")
sine square sawtooth triangleシンセサイザーの 基本の 波の 形。sine = やわらかい、square = ピコピコ、sawtooth = ギザギザで 明るい、triangle = すっきり。
note("c4").s("sawtooth")
supersawノコギリ波を 何本も 少しずつ ずらして かさねた、分厚くて キラキラした 音。
note("[a3,c4,e4]").s("supersaw")
whiteザーッという ノイズ。ビルドアップで だんだん 大きく する 音(ライザー)に つかう。
s("white*16")
なまえと れきし

sound(音)の 略。TidalCycles の 音源 SuperDirt で つかわれていた 名前を そのまま 受けついでいる。

bd sd hh oh cp rim lt mt ht cr: ドラムマシンの つまみに 書かれていた 略語が もとで、TidalCycles の 音の フォルダ名として 広まった。bd = bass drum、sd = snare drum、hh = hi-hat。

sbd: 音が 低い 方へ すべり 落ちる「ドゥン」という キックは、TR-808 の キックと 同じ しくみ(高さを すばやく 下げる)。

sine square sawtooth triangle: どれも 波の 形の 名前。sine は 数学の 正弦(サイン)波、square は 四角、sawtooth は「ノコギリの 歯」、triangle は 三角。1960年代の アナログシンセから ずっと つかわれている。

supersaw: 1997年ごろに 出た ローランドの シンセ JP-8000 の 機能の 名前。7本の ノコギリ波を かさねる この 音が、トランスという 音楽の 代表的な 音に なった。

white: ホワイトノイズ。白い 光に すべての 色が まざっている ように、すべての 高さの 音が 同じ くらい まざっているから「白」と よばれる。

音の高さ [ ] Strudel: note ビギナー

何が 起きる?

音の 高さを 音名(c4)や 数字(60 = c4)で 書く。下に「音」を 置くと、その 音色で 鳴るよ。

ためしてみよう

ピアノで ド ミ ソ と 鳴る。

よく つかう 場面

  • メロディや ベースを 書く
  • [c4,e4,g4] と カンマで 書いて、和音を 鳴らす

Strudel では

note("c4 e4 g4").s("piano")
なまえと れきし

英語で「音符」。数字は MIDI(1983年に きまった 電子楽器の 共通ルール)の 番号で、60 が まんなかの ド。

音階の番号 [ ] Strudel: n ノーマル

何が 起きる?

音階の 中の 何番目の 音かを 番号で 書く。下に「音階」を 置くと、番号が その 音階の 音に なる。0 が 1番目。番号で 書くと、どんな 音階でも 音を はずさないよ。

ためしてみよう

ド ミ ソ ド(上の)と 鳴る。

よく つかう 場面

  • メロディを 音階から はずれない ように 書く
  • 「音階」だけ かえて、同じ メロディを 明るく したり 暗く したり する

Strudel では

n("0 2 4 7").scale("C4:major").s("piano")
なまえと れきし

n は number(番号)。

順番に [ ] [ ] [ ] [ ] Strudel: seq ビギナー

何が 起きる?

音を 1サイクルの 中に 順番に ならべる。4つ ならべると、1つが 1/4 サイクルずつ 鳴るよ。

ためしてみよう

ドン チッ タン チッ と 鳴る。

よく つかう 場面

  • ビギナーで リズムを 組む。▼ で ~(休み)を えらぶと、音を 鳴らさない マスが 作れる

Strudel では

seq(s("bd"), s("hh"), s("sd"), s("hh"))
なまえと れきし

sequence(シーケンス、ならび)の 略。音を 順番に 鳴らす 機械「シーケンサー」と 同じ ことばだよ。ミニ記法では 空白で 区切って ならべる("bd hh sd hh")。

重ねる [ ] [ ] Strudel: stack ビギナー

何が 起きる?

音を 同時に かさねて 鳴らす。

ためしてみよう

キックと ハイハットが いっしょに 4回 鳴る。

よく つかう 場面

  • ビギナーで 2つの 音を いっしょに 鳴らす。もっと 重ねるなら、C型の「重ねる」か、トラックを 分ける

Strudel では

stack(s("bd"), s("hh")).fast(4)
なまえと れきし

英語で「つみかさねる」。ミニ記法では ,(カンマ)で 同じ ことが できるよ("bd, hh")。

重ねる(C型) Strudel: stackBranch ノーマル

何が 起きる?

C型の 中に 積んだ ブロックを べつの 鎖として、上の 音と 同時に 鳴らす。中の ブロックは 中の 音だけに かかり、下に 積んだ ブロックは ぜんぶの 音に かかるよ。

ためしてみよう

キックと スネアが いっしょに、TR-909 の 音で 鳴る。

よく つかう 場面

  • ドラムの 楽器ごとに 欄を 分けて、短く 読みやすく 書く(リズム図鑑)

Strudel では

stack(s("bd*4"), s("[~ sd]*2")).bank("RolandTR909")
なまえと れきし

Strudel の stack( , ) の カンマ 1つ分が、このブロック 1つ分。トラックを 分けると 1本ずつ 止められ、stack で 重ねると まとめて 止まるよ。

サイクルごとに [ ] [ ] Strudel: cat ビギナー

何が 起きる?

1サイクルごとに 交互に 鳴らす。1回目は c4、2回目は g4、3回目は また c4…。

ためしてみよう

ド ソ ド ソ と 交互に 鳴る。

よく つかう 場面

  • サイクルごとに ベースの 音を かえる

Strudel では

cat(note("c4"), note("g4")).fast(4)
なまえと れきし

concatenate(つなげる)の 略。プログラミングでは 文字を つなげる ときに よく つかう 名前だよ。ミニ記法の < > と 同じ。

スプライトの音 [ ] ノーマル

何が 起きる?

スプライトの「音」タブに ある 音(録音した 声など)を、ドラムの ように 鳴らす。

ためしてみよう

ねこの「ニャー」が 2回 鳴る。

よく つかう 場面

  • じぶんの 声で ビートを つくる(チュートリアル 10章)

Strudel では

Strudel には ない、この 拡張だけの ブロック だよ。

Strudel では samples() で 音の ファイルを 読みこんで 鳴らす。スプライトの 音は strudel.cc からは 読めないので、書き出した コードでは 鳴らないよ。

和音 [ ] [ ] マスター

何が 起きる?

根音(ルート)と 種類を えらんで、和音を 鳴らす。major は 明るい、minor は 暗い、7 や maj7 は おしゃれな ひびき。

ためしてみよう

ド ミ ソ シ が いっしょに 鳴る。

よく つかう 場面

  • 下に「アルペジオ」を 置いて 1音ずつ 鳴らす
  • 「リズムで鳴らす」で 和音を きざむ

Strudel では

note("[c4,e4,g4,b4]").s("piano")
なまえと れきし

英語で「和音」。もとは accord(一致、調和)と 同じ ことばだよ。

音を かえる

ここからの ブロックは、トラックの 中で 音の ブロックの 下に 積む。上から じゅんばんに かかるよ。

はやくする [ ] Strudel: fast ビギナー

何が 起きる?

パターンを N倍の 速さに する。1つの 音なら、1サイクルに N回 鳴る。

ためしてみよう

ハイハットが 1サイクルに 8回、チッチッチッチッ…と きざむ。

よく つかう 場面

  • ハイハットを きざむ(8 で 8分音符、16 で 16分音符)
  • メロディを 2倍の 速さで くりかえす

Strudel では

s("hh").fast(8)
なまえと れきし

TidalCycles から ある 基本の 名前。ミニ記法の * と 同じ("hh*8")。

おそくする [ ] Strudel: slow ノーマル

何が 起きる?

パターンを N倍 ゆっくり に して、Nサイクルに のばす。

ためしてみよう

4つの 音が 2サイクル かけて、ゆっくり 鳴る。

よく つかう 場面

  • 長く のばす パッドや 和音を ゆっくり かえる

Strudel では

note("c4 e4 g4 b4").slow(2).s("piano")
なまえと れきし

fast の 反対。ミニ記法の / と 同じ("c4/2")。

音階 [ ] [ ] Strudel: scale ノーマル

何が 起きる?

「音階の番号」の 番号を、えらんだ 音階の 音に かえる。根音(C4 など)と 音階の 種類を えらぶよ。

ためしてみよう

ド レ ミ♭ ファ ソ と、暗い ひびきで 上がる。

よく つかう 場面

  • 同じ 番号の まま 音階を かえて、曲の 気分を かえる

Strudel では

n("0 1 2 3 4").scale("C4:minor").s("piano")

えらべる 名前

名前何が 起きる?
major minormajor は 明るい 音階(長調)、minor は 暗い 音階(短調)。
n("0 2 4").scale("C4:minor")
major:pentatonic minor:pentatonic5つの 音だけの 音階。どう ならべても きれいに 聞こえる。
n("0 1 2 3 4").scale("C4:major:pentatonic")
blues dorian chromaticblues は ブルースの 音階、dorian は ジャズや ケルト音楽で 好まれる 音階、chromatic は 半音を ぜんぶ ならべた 音階。
n("0 1 2 3").scale("C4:dorian")
なまえと れきし

英語で「音階」。もとは ラテン語の scala =「はしご」。音が はしごの 段の ように ならぶから。

major minor: 英語で major =「大きい」、minor =「小さい」。ドと ミの 間(3度)が 大きいか 小さいかで 名前が ついた。

major:pentatonic minor:pentatonic: ギリシャ語の penta(5)+ tonic(音)。日本の「ヨナ抜き音階」も その 仲間(4番目と 7番目を ぬく)。

blues dorian chromatic: dorian は 古代ギリシャの ドーリア人から 名前を とった 音階で、中世の 教会音楽を へて 今に つたわる。chromatic は ギリシャ語の chroma(色)から。

リズムで鳴らす [ ] Strudel: struct ノーマル

何が 起きる?

x と ~ で 書いた リズムで、音を きざむ。x で 鳴らし、~ で 休む。

ためしてみよう

和音が ジャン・・ジャン ジャン と リズムに のる。

よく つかう 場面

  • 和音を リズムに のせて、ピアノや ギターの ような 伴奏に する

マスで鳴らす [ ] [ ] Strudel: beat ノーマル

何が 起きる?

1サイクルを Nこの マスに 分けて、番号の マスで 鳴らす。0 が 1番目の マス。, で 番号を ならべ、7? の ように ? を つけると その マスは ときどき 鳴らない。

ためしてみよう

キックが 拍から ずれた 場所で 鳴って、はずむ。

よく つかう 場面

  • ばらばらの 場所で 鳴る キックや スネアを 書く(リズム図鑑)

Strudel では

s("bd").beat("0,7,10", 16)
なまえと れきし

英語で「拍」。16マスに 音を おいていく やりかたは、TR-808 などの ドラムマシンが 16この ボタンで リズムを 組んだ のと 同じ 考えかただよ。

ドラムマシン [ ] Strudel: bank ノーマル

何が 起きる?

ドラムの 音を、えらんだ ドラムマシンの 音に かえる。

ためしてみよう

キックが TR-909 の かたい 音に なる。

よく つかう 場面

  • ハウスや テクノは TR-909、ヒップホップや トラップは TR-808 に する

Strudel では

s("bd*4").bank("RolandTR909")
なまえと れきし

sample bank(サンプルの 倉庫)から。TR-808(1980年)と TR-909(1983年)は ローランドの ドラムマシンで、ヒップホップや ハウス、テクノの 音を つくった 名機だよ。

効果 [ ▼] [ ] ノーマル

何が 起きる?

▼で えらんだ 効果(エフェクト)を かける。数字の 欄には、ミニ記法の パターンや「ゆれる値」も 入れられるよ。数字は 効果ごとに きまった 範囲の 中に おさめられる(範囲より 大きい 数は いちばん 大きい 数に なる)。範囲と 目安は 下の 表を 見てね。

ためしてみよう

ギザギザの ベースの 高い 音が けずれて、こもった 太い 音に なる。

よく つかう 場面

  • ベースを こもらせる、ドラムに ひびきを つける、ハイハットの 音量を 小さく する
  • 1つの 音に 効果を いくつも 重ねる(上から じゅんばんに かかる)

Strudel では

note("c2*4").s("sawtooth").lpf(600)

なまえと れきし

▼ の 名前は 日本語や カタカナ だけど、1つ 1つが Strudel の 関数に なる。下の 一覧で どの 関数かを しらべよう。

lpf hpf: low-pass filter(低い 音を 通す フィルター)、high-pass filter。1960年代に ロバート・モーグさんが つくった シンセの フィルターが 有名。

lpq: q は 電気の ことばで「Q値(きれの するどさ)」。

lpenv lpd lps: env = envelope(エンベロープ、音の 形の 変化)。d = decay、s = sustain(下の ADSR を 見てね)。

attack decay sustain release: 4つの 頭文字で「ADSR」。1960年代に、電子音楽の 研究者 ウラジミール・ウサチェフスキーさんが 考えたと いわれ、今の ほとんどの シンセに ある。

room: 英語で「部屋」。部屋の 大きさで ひびきかたが かわる ことから。

delay delaytime delayfeedback: 英語で「おくれ」。むかしは 録音テープを ループさせて やまびこを つくっていた(ローランドの Space Echo、1974年 など)。

gain: 英語で「増やす、もうけ」。電気の 信号を 何倍に するか、という 意味の ことば。

pan: panorama(パノラマ、見わたす けしき)から。音を 左右の けしきの どこに おくか、という 意味。

crush: 音の 細かさ(ビット数)を 「つぶす」 から crush。むかしの ゲーム機の 8ビットの 音に 近く なる。

distort: エレキギターの「ひずみ」と 同じ。1950〜60年代、アンプの 音量を 上げすぎて 音が こわれたのが、かっこいい 音として 広まった。

speed: レコードや テープを 速く まわすと 音が 高く なる のと 同じ しくみ。

clip: 英語で「切りとる」。

vowel: 英語で「母音」。人の 声の 母音を つくる 響き(フォルマント)を まねる フィルター。

unison detune spread: unison(ユニゾン)は ラテン語で「1つの 音」。何人もが 同じ 音を 歌う ことだよ。detune は「チューニングを はずす」。

fm: frequency modulation(周波数変調。FM ラジオと 同じ ことば)。1967年に スタンフォード大学の ジョン・チャウニングさんが 発見し、1983年の ヤマハ DX7 で 世界中に 広まった。

orbit: 英語で「軌道」。TidalCycles の 音源 SuperDirt で、トラックごとの 効果が まざらない ように 分ける しくみの 名前だよ。

duck duckattack duckdepth: 英語で「ひょいと 頭を 下げる」。ラジオで 話す ときに 音楽を 小さく する わざ「ダッキング」から。クラブミュージックでは「サイドチェイン」「ポンピング」とも いい、2000年代の フレンチハウスや EDM で 流行した。

音を上げ下げ [ ] Strudel: add ノーマル

何が 起きる?

音の 高さ(番号)に 数を たす。<0 2 4> の ように パターンも たせる。

  • 同じ フレーズを 高さを かえて くりかえす

n("0 2 4").add(n("<0 2 4>")).scale("C4:major").s("piano")
なまえと れきし

英語で「たす」。

何が 起きる?

パターンを 逆さまに、うしろから 鳴らす。

ためしてみよう

ソ ミ レ ド と、うしろから 鳴る。

よく つかう 場面

  • 「サイクルごとに変える」と くみあわせて、ときどき 逆に する

何が 起きる?

パターンの 1つ 1つの 音を N回ずつ くりかえす。

ドンドン タンタン と、1つずつ 2回 鳴る。

s("bd sd").ply(2)

何が 起きる?

Nサイクルに 1回 だけ、▼の かえかたを する。▼ には ぎゃく・はやく・おそく・くりかえし・1オクターブ上・5度上 が ある。

4サイクルに 1回、メロディが 逆に なる。

  • ずっと 同じに ならない ように、ときどき 変化を つける(フィル)

ランダムに抜く [ ] % Strudel: degradeBy マスター

ハイハットが ところどころ ぬけて、人が たたいている ように 聞こえる。

  • こまかい ハイハットを まばらに して、ループに ゆらぎを つける

s("hh*16").degradeBy(0.3)
なまえと れきし

degrade は「質を 落とす、こわす」。ミニ記法の ? と 同じ("hh*16?")。

ときどき(半分 くらいの 音に)▼の かえかたを する。

ユークリッド [ ] [ ] Strudel: euclid マスター

何が 起きる?

Nこの 音を、Mこの マスに できるだけ 均等に ちらす。(3, 8) は 世界中の 音楽で 聞こえる リズム。

ためしてみよう

カッ・・カッ・・カッ・ と、3・3・2 の リズムで 鳴る。

  • 4つ打ちの 上に 重ねて、ひっかかりの ある リズムに する(リズム図鑑)

アシッド [ ] マスター

何が 起きる?

ノコギリ波と フィルターを セットに して、アシッドの「ビヨビヨ」した 音に する。数字が 大きいほど よく うごく。

ためしてみよう

よく つかう 場面

  • アシッドハウスの ベース(チュートリアル 12章)

トランスゲート [ ] [ ] [ ] マスター

何が 起きる?

長い 和音を 細かく きざんで、トランスの「タタタタ」と いう 音に する。1つめの 数字が 鳴る マスの 多さ、2つめが リズムの たね(かえると ちがう リズム)。

ためしてみよう

分厚い 和音が タタ・タタタ と きざまれる。

よく つかう 場面

  • トランスの パッド(チュートリアル 12章)

Strudel では

note("[a3,c4,e4]").s("supersaw").struct(rand.mul(1.2).round().seg(16).rib(12, 1)).fillGaps().clip(0.7)
なまえと れきし

トランスという 音楽で 1990年代の おわりごろから よく つかわれる「ゲート」(音を 開け閉めする 門)の わざ。名前は Switch Angel さんの strudel-scripts の 関数 trancegate から。書き出すと struct・fillGaps・clip に なる。

値の ブロック

丸い ブロックは、ほかの ブロックの 欄に 入れて つかう。

リスト [ ] の中身を [ ] ならべる ノーマル

何が 起きる?

Scratch の リストの 中身を ならべて、ミニ記法に する。▼ で ならべかたを えらぶ。「1サイクルに1つずつ」は 1行が 1小節、「1サイクルの中に順番に」は 1サイクルに ぜんぶ、「ぜんぶ同時に」は 重ねる。

ためしてみよう

リスト「メロディ」には c4 e4、g4 e4、a4 g4、e4 d4 の 4行が 入っている。1行が 1小節ずつ 順番に 鳴るよ。

よく つかう 場面

  • 長い メロディや コード進行を、1小節ずつ リストに 書く(チュートリアル 9章)
  • ドラムを 楽器ごとに 1行ずつ 書いて「ぜんぶ同時に」で 重ねる

Strudel では

note("<[c4 e4] [g4 e4] [a4 g4] [e4 d4]>").s("piano")
なまえと れきし

Strudel には リストが ないので、書き出すと ミニ記法の < >(1サイクルずつ)、[ ](順番に)、,(同時に)に なるよ。

ゆれる値 [ ] [ ] から [ ] [ ] サイクル Strudel: range マスター

何が 起きる?

時間で ゆれる 値。波の 形を えらび、何から 何まで、何サイクルで ゆれるかを きめる。数字の かわりに 効果に 入れると、音が ゆっくり かわっていく。

ためしてみよう

ベースが 4サイクル かけて こもったり 明るく なったり する。

よく つかう 場面

  • フィルターを ゆっくり 開いて もりあげる(リズム図鑑)
  • 「音の大きさ」に 入れて、だんだん 大きく する

Strudel では

note("c2*8").s("sawtooth").lpf(sine.range(200, 2000).slow(4))
なまえと れきし

シンセサイザーの「LFO」(ゆっくり ゆれる 波)と 同じ はたらき。波の 形の ゆらゆら(perlin)は ケン・パーリンさんが 1983年に つくった「なめらかな 乱数」で、映画の CG を 自然に 見せる ために 生まれ、1997年に アカデミー賞(科学技術賞)を もらった。

乱数 [ ] から [ ] を [ ] こ たね [ ] 長さ [ ] Strudel: irand マスター

何が 起きる?

乱数で 番号を つくる。何から 何まで、1サイクルに 何こ、どの「たね」の 乱数を 何サイクル くりかえすかを きめる。同じ たねなら いつも 同じ フレーズに なるよ。

ためしてみよう

音階の 中で ランダムな 8つの 音が 鳴り、毎サイクル 同じ フレーズを くりかえす。

よく つかう 場面

  • たねを かえながら、気に入った メロディを さがす

Strudel では

n(irand(8).add(0).seg(8).rib(3, 1)).scale("C4:minor:pentatonic").s("piano")
なまえと れきし

irand = integer(整数)の random(乱数)。seg = segment(区切る)、rib = ribbon(リボン)の 略。

音を 見る

[ ] を表示する ビギナー

何が 起きる?

ステージに 音の 絵を 出す。▼で 絵の 種類を えらぶよ。

ためしてみよう

ステージに ピアノロールが 出て、鳴っている 音が 帯で 流れる。

よく つかう 場面

  • メロディは ピアノロール、ドラムは パンチカード、音色は スコープや スペクトルで 見る

Strudel では

note("c4 e4 g4")._pianoroll()

えらべる 名前

名前何が 起きる?
スコープ
scope		音の 波の 形を 線で 見せる。
s("sawtooth")._scope()
ピアノロール
pianoroll		音の 高さと 長さを、横に 流れる 帯で 見せる。
note("c4 e4 g4")._pianoroll()
スペクトル
spectrum		低い 音から 高い 音まで、どれが どれくらい 鳴っているかを 見せる。
s("bd hh")._spectrum()
パンチカード
punchcard		ピアノロールを 穴の あいた カードの ように 見せる。
note("c4 e4 g4")._punchcard()
なまえと れきし

Strudel では パターンの うしろに ._pianoroll() などを つける。

scope: oscilloscope(オシロスコープ)の 略。電気の 波を 見る 測定器。

pianoroll: 1900年ごろの 自動ピアノは、穴の あいた 紙の ロール(巻物)で 曲を 演奏した。その 見た目が もとに なった 名前。

spectrum: 英語で「スペクトル」。光を プリズムに 通すと 虹色に 分かれる ように、音を 高さごとに 分けて 見る。

punchcard: パンチカードは 穴の 位置で 情報を あらわす カード。1800年代の はじめ、ジャカールの 織機が 布の 模様を あやつる のに つかい、のちに コンピューターにも つかわれた。
