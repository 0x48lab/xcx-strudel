関数じてん

ブロックの 名前が どんな ものか、どこから 来たのかを しらべよう。
Strudel for Xcratch ・ チュートリアル

この 拡張機能の ブロックや ▼には、日本語の 説明と いっしょに Strudel の 関数の 名前が 書いてあるよ(「はやくする fast」の fast)。音楽で そのまま つかう ことばは、カタカナで 書いてあるよ(「アルペジオ」は arp、「ディレイ」は delay)。音の 名前(bd など)は Strudel と 同じだよ。この じてんでは、1つ 1つの 名前が どんな ものか、そして どこから 来た 名前か(かんたんな れきし)を しょうかいするよ。

「ブロック:」は、「トラック [ ] で鳴らす」の 中に 入れる ブロックの すがただよ。中の ブロックは 上から じゅんばんに、Strudel の .fast(4) のような 1だんずつに なるよ。

Strudel の 名前は どこから 来たの?

Strudel の もとに なったのは、TidalCycles(タイダルサイクルズ)という 音楽の プログラミング言語だよ。イギリスの Alex McLean(アレックス・マクリーン)さんが 2009年ごろに Haskell という 言語で つくり、その場で コードを 書きかえながら 演奏する「ライブコーディング」の 道具として 世界中で つかわれてきた。

2022年、Felix Roos(フェリックス・ロース)さんと Alex McLean さんが、TidalCycles の しくみを JavaScript に うつして、ブラウザだけで 鳴らせるように した。これが Strudel だよ。だから fast rev every jux などの 名前の 多くは、TidalCycles から 受けついだ ものなんだ。「サイクル」で 時間を 数える 考えかたも、TidalCycles の 名前の とおりだね。

音の 名前(bd lpf sawtooth など)は、もっと 古く、ドラムマシンや シンセサイザーの れきしから 来ているよ。

ならべる・かさねる

seq ビギナー

ブロック: 順番に seq [bd] [hh] [sd] [hh]

音を 1サイクルの 中に 順番に ならべる。4つ ならべると、1つが 1/4 サイクルずつ 鳴るよ。

seq(s("bd"), s("hh"), s("sd"), s("hh"))

sequence(シーケンス、ならび)の 略。音を 順番に 鳴らす 機械「シーケンサー」と 同じ ことばだよ。

stack ビギナー

ブロック: 同時に stack [bd] [cr]

音を 同時に かさねて 鳴らす。ドラムと ベースを いっしょに 鳴らすときに つかうよ。

stack(s("bd"), s("cr"))

英語で「つみかさねる」。ミニ記法では ,(カンマ)で 同じ ことが できるよ("bd, cr")。

重ねる stack ノーマル

ブロック: トラックの 中に 重ねる stack(C型)

C型の 中に 積んだ ブロックを べつの 鎖として、上の 音と 同時に 鳴らす。中の beat などは 中の 音だけに かかる。下に 積んだ orbit などは ぜんぶの 音に かかるよ。

stack(s("bd").beat("0,10", 16), s("sd").beat("4,12", 16)).orbit(2)

Strudel の stack( , ) の カンマ 1つ分が、このブロック 1つ分。トラックを 分けると 1本ずつ 止められ、stack で 重ねると まとめて 止まるよ。

cat ビギナー

ブロック: サイクルごとに cat [c4] [g4]

1サイクルごとに 交互に 鳴らす。1回目は c4、2回目は g4、3回目は また c4…。

cat(note("c4"), note("g4"))

concatenate(つなげる)の 略。プログラミングでは 文字を つなげる ときに よく つかう 名前だよ。ミニ記法の < > と 同じ。

fast ビギナー

ブロック: はやくする fast [4]

パターンを N倍の 速さに する。1つの 音なら、1サイクルに N回 鳴る。

s("hh").fast(4)

TidalCycles から ある 基本の 名前。ミニ記法の * と 同じ("hh*4")。

slow ノーマル

ブロック: おそくする slow [2]

パターンを N倍 ゆっくり に して、Nサイクルに のばす。

note("c4").slow(2)

fast の 反対。ミニ記法の / と 同じ("c4/2")。

struct ノーマル

ブロック: リズムで鳴らす struct [x ~ x x]

x と ~ で 書いた リズムで、音を きざむ。和音を リズムに のせる ときに 便利。

note("[c3,e3,g3]").struct("x ~ x x")

structure(つくり、骨組み)の 略。リズムの「骨組み」だけを ほかの パターンから かりてくる、という 意味だよ。

beat ノーマル

ブロック: マスで鳴らす beat [0,7,10] [16]

1サイクルを Nこの マスに 分けて、番号の マスで 鳴らす。0 が 1番目の マス。, で 番号を ならべ、7? の ように ? を つけると その マスは ときどき 鳴らない。

s("bd").beat("0,7?,10", 16)

英語で「拍」。16マスに 音を おいていく やりかたは、TR-808 などの ドラムマシンが 16この ボタンで リズムを 組んだ のと 同じ 考えかただよ。

音を えらぶ

s ビギナー

ブロック: 音 s [bd ▼] / 音 s [bd sd]

鳴らす 音の 種類を きめる。ドラムの 名前(bd)も、シンセの 波の 形(sawtooth)も、ぜんぶ s で えらぶよ。

s("bd sd")  /  note("c4").s("sawtooth")

sound(音)の 略。TidalCycles の 音源 SuperDirt で つかわれていた 名前を そのまま 受けついでいる。

note ビギナー

ブロック: 音の高さ note [c4 ▼] / 音の高さ note [c4 e4 g4]

音の 高さを 音名(c4)や 数字(60 = c4)で 書く。

note("c4 e4 g4")

英語で「音符」。数字は MIDI(1983年に きまった 電子楽器の 共通ルール)の 番号で、60 が まんなかの ド。

n + scale ノーマル

ブロック: 音階の番号 n [0 2 4] + 音階 scale [C4] [major]

n で 番号を 書き、scale で その 番号を 音階の 音に かえる。0 が 1番目の 音。番号で 書くと、どんな 音階でも はずれない。

n("0 2 4").scale("C4:major")

n は number(番号)。scale は 英語で「音階」(もとは ラテン語の scala =「はしご」。音が はしごの 段の ように ならぶから)。

bank ノーマル

ブロック: ドラムマシン bank [RolandTR909]

ドラムの 音を、ドラムマシンの 機種の 音に かえる。

s("bd*4").bank("RolandTR909")

sample bank(サンプルの 倉庫)から。TR-808(1980年)と TR-909(1983年)は ローランドの ドラムマシンで、ヒップホップや ハウス、テクノの 音を つくった 名機だよ。

bd sd hh oh cp rim lt mt ht cr ビギナー

ブロック: ▼ の ドラム

ドラムの 音の 名前。bd = バスドラム、sd = スネア、hh = ハイハット、oh = オープンハイハット、cp = クラップ(手拍子)、rim = リム、lt / mt / ht = 低い / 中くらい / 高い タム、cr = クラッシュシンバル。

s("bd hh sd hh")

ドラムマシンの つまみに 書かれていた 略語が もとで、TidalCycles の 音の フォルダ名として 広まった。bd = bass drum、sd = snare drum、hh = hi-hat。

sbd ビギナー

ブロック: ▼ の sbd

シンセサイザーで つくった キック(synth bass drum)。録音した 音ではなく、計算で 鳴らしているよ。

s("sbd!4")

音が 低い 方へ すべり 落ちる「ドゥン」という キックは、TR-808 の キックと 同じ しくみ(高さを すばやく 下げる)。

sine square sawtooth triangle ビギナー

ブロック: 音 s [sawtooth ▼]

シンセサイザーの 基本の 波の 形。sine = やわらかい、square = ピコピコ、sawtooth = ギザギザで 明るい、triangle = すっきり。

note("c4").s("sawtooth")

どれも 波の 形の 名前。sine は 数学の 正弦(サイン)波、square は 四角、sawtooth は「ノコギリの 歯」、triangle は 三角。1960年代の アナログシンセから ずっと つかわれている。

supersaw ビギナー

ブロック: 音 s [supersaw ▼]

ノコギリ波を 何本も 少しずつ ずらして かさねた、分厚くて キラキラした 音。

note("[a3,c4,e4]").s("supersaw")

1997年ごろに 出た ローランドの シンセ JP-8000 の 機能の 名前。7本の ノコギリ波を かさねる この 音が、トランスという 音楽の 代表的な 音に なった。

white ビギナー

ブロック: 音 s [white ▼]

ザーッという ノイズ。ビルドアップで だんだん 大きく する 音(ライザー)に つかう。

s("white*16")

ホワイトノイズ。白い 光に すべての 色が まざっている ように、すべての 高さの 音が 同じ くらい まざっているから「白」と よばれる。

パターンを かえる

add ノーマル

ブロック: 音を上げ下げ add [7]

音の 高さ(番号)に 数を たす。"<0 2 4>" の ように パターンも たせる。

note("c4").add(note("<0 7>"))

英語で「たす」。

transpose マスター

ブロック: 音をずらす transpose [12]

音を 半音 N個ぶん 上げる(マイナスなら 下げる)。12 で 1オクターブ。

note("c4").transpose(12)

音楽の ことばで「移調」。歌いやすい 高さに 曲ぜんたいを ずらす ときに つかう。

rev ノーマル

ブロック: ぎゃくにする rev

パターンを 逆さまに、うしろから 鳴らす。

s("bd hh sd hh").rev()

reverse(逆)の 略。

ply ノーマル

ブロック: くりかえす ply [2]

パターンの 1つ 1つの 音を N回ずつ くりかえす。

s("bd sd").ply(2)

英語で「(糸の)より、重ね」。1本の 糸を 何重にも する イメージだよ。TidalCycles から ある 名前。

every ノーマル

ブロック: サイクルごとに変える every [4] [ぎゃく]

Nサイクルに 1回 だけ、▼の 関数を かける。

note("c4 e4 g4").every(4, x => x.rev())

英語で「〜ごとに」。TidalCycles の はじめの ころから ある、いちばん 有名な 関数の 1つ。

sometimes マスター

ブロック: ときどき変える sometimes [1オクターブ上]

ときどき(半分 くらいの 音に)▼の 関数を かける。

note("c4*8").sometimes(x => x.transpose(12))

英語で「ときどき」。仲間に often(よく)、rarely(たまに)も あるよ。

degradeBy マスター

ブロック: ランダムに抜く degradeBy [30] %

音を 確率で 休ませる。ハイハットを 少し まばらに すると 人が たたいた ように 聞こえる。

s("hh*16").degradeBy(0.3)

degrade は「質を 落とす、こわす」。ミニ記法の ? と 同じ("hh*16?")。

euclid マスター

ブロック: ユークリッド [3] [8]

Nこの 音を、Mこの マスに できるだけ 均等に ちらす。(3, 8) は 世界中の 音楽で 聞こえる リズム。

s("bd").euclid(3, 8)

計算幾何学者の ゴドフリー・トゥーサンさんが、2つの 数の 最大公約数を もとめる「ユークリッドの 互除法」(2300年ほど 前の 古代ギリシャの 数学)と 同じ 手順で、キューバや アフリカの 伝統的な リズムが つくれる ことを 2004〜2005年ごろの 論文で 示した。もとの 手順は、物理学者の ビョークランドさんが 加速器の タイミングを きめる ために つかっていた ものだよ。

jux マスター

ブロック: ジャックス [ぎゃく]

音を 左右に 分けて、右だけに ▼の 関数を かける。左右で ちがう 音が 鳴って 広がる。

s("bd hh sd hh").jux(x => x.rev())

juxtapose(ならべて おく)の 略。TidalCycles 生まれの 名前。

off マスター

ブロック: ずらして重ねる off [1/8] [5度上]

少し おくらせて、▼の 関数を かけた ものを かさねる。やまびこの ような、ずれた 音が できる。

note("c4 e4").off(0.125, x => x.transpose(7))

英語で「ずれて、はなれて」。TidalCycles から ある 名前。

superimpose マスター

ブロック: スーパーインポーズ [1オクターブ上]

▼の 関数を かけた ものを、もとの パターンに かさねる。

note("c4 e4").superimpose(x => x.transpose(12))

英語で「重ねあわせる」。写真を 二重に うつす 技法(スーパーインポーズ)と 同じ ことば。

chop マスター

ブロック: チョップ [4]

1つの 音を Nこに 切って、細かく 鳴らす。

s("bd").chop(4)

英語で「切る、きざむ」。録音した 音を 細かく 切って ならべなおすのは、1980年代の サンプラーから 広まった ヒップホップの わざだよ。

arp マスター

ブロック: アルペジオ [0 1 2 1]

和音の 音を、番号の 順に 1つずつ 鳴らす(アルペジオ)。

note("[c4,e4,g4]").arp("0 1 2 1")

arpeggio(アルペジオ)の 略。イタリア語の arpa(ハープ)から。ハープの ように 和音を ばらして 弾く ことだよ。

ゆれる 値・乱数

sine saw square tri rand perlin + range マスター

ブロック: ゆれる値 [なめらか sine] range [200] [2000] slow [4]

時間で ゆれる 値。数字の かわりに 効果に 入れると、音が ゆっくり かわっていく。

sine.range(200, 2000).slow(4)

シンセサイザーの「LFO」(ゆっくり ゆれる 波)と 同じ はたらき。perlin は ケン・パーリンさんが 1983年に つくった「なめらかな 乱数」で、映画の CG を 自然に 見せる ために 生まれ、1997年に アカデミー賞(科学技術賞)を もらった。

irand + seg + rib マスター

ブロック: 乱数 irand [-7] .. [2] seg [16] rib [46] [1]

乱数で 番号を つくる。seg で 1サイクルに 何こ とるか、rib で どの サイクルの 乱数を くりかえすか を きめる。同じ 番号なら いつも 同じ フレーズ。

n(irand(10).add(-7).seg(16).rib(46, 1))

irand = integer(整数)の random(乱数)。seg = segment(区切る)、rib = ribbon(リボン)の 略。

効果(エフェクト)

lpf / hpf ノーマル

ブロック: [ひくい音だけ通す lpf ▼] [600]

lpf は 高い 音を けずって こもらせる。hpf は 低い 音を けずって シャカシャカに する。数字は どこから けずるか(Hz)。

s("sawtooth").lpf(600)

low-pass filter(低い 音を 通す フィルター)、high-pass filter。1960年代に ロバート・モーグさんが つくった シンセの フィルターが 有名。

lpq ノーマル

ブロック: [フィルターのクセ lpq ▼] [12]

フィルターの 境目を 強調して、「ミョーン」と くせの ある 音に する(レゾナンス)。

s("sawtooth").lpf(400).lpq(12)

q は 電気の ことばで「Q値(きれの するどさ)」。

lpenv / lpd / lps ノーマル

ブロック: [フィルターの動き lpenv ▼] [4]

音が 鳴るたびに フィルターを 開いて 閉じる。lpd は 閉じるまでの 時間、lps は 残る 量。アシッドの「ビヨッ」は これ。

note("a1*8").s("sawtooth").lpf(200).lpenv(4)

env = envelope(エンベロープ、音の 形の 変化)。d = decay、s = sustain(下の ADSR を 見てね)。

attack decay sustain release ノーマル

ブロック: [アタック ▼] [.5]

音量の 形。attack = 鳴りはじめの ゆっくりさ、decay = 下がる 時間、sustain = 残る 大きさ、release = 鳴りおわりの 余韻。

note("c4").s("sine").attack(.5).release(2)

4つの 頭文字で「ADSR」。1960年代に、電子音楽の 研究者 ウラジミール・ウサチェフスキーさんが 考えたと いわれ、今の ほとんどの シンセに ある。

room ノーマル

ブロック: [ひびき room ▼] [.5]

ひびき(リバーブ)。広い 部屋で 鳴らした ように なる。

s("sd").room(.5)

英語で「部屋」。部屋の 大きさで ひびきかたが かわる ことから。

delay / delaytime / delayfeedback ノーマル

ブロック: [ディレイ ▼] [.4]

やまびこ。少し おくれて 同じ 音が くりかえす。delaytime は 間かく、delayfeedback は くりかえしの 多さ。

note("c4 e4").delay(.4).delaytime(.25)

英語で「おくれ」。むかしは 録音テープを ループさせて やまびこを つくっていた(ローランドの Space Echo、1974年 など)。

gain ノーマル

ブロック: [音の大きさ gain ▼] [.8]

音の 大きさ。1 が ふつう。

s("hh*8").gain(.6)

英語で「増やす、もうけ」。電気の 信号を 何倍に するか、という 意味の ことば。

pan ノーマル

ブロック: [パン ▼] [0]

左右の 位置。0 が 左、0.5 が まんなか、1 が 右。

s("hh*8").pan(sine.range(0, 1))

panorama(パノラマ、見わたす けしき)から。音を 左右の けしきの どこに おくか、という 意味。

crush ノーマル

ブロック: [ガサガサにする crush ▼] [4]

音を ガリガリ に する(ビットクラッシャー)。数字が 小さいほど あらい。

s("bd sd").crush(4)

音の 細かさ(ビット数)を 「つぶす」 から crush。むかしの ゲーム機の 8ビットの 音に 近く なる。

distort ノーマル

ブロック: [ディストーション ▼] [2]

ひずみ(ディストーション)。音を 歪ませて 太く、あらく する。

note("a1").s("sawtooth").distort(2)

エレキギターの「ひずみ」と 同じ。1950〜60年代、アンプの 音量を 上げすぎて 音が こわれたのが、かっこいい 音として 広まった。

speed ノーマル

ブロック: [再生の速さ speed ▼] [2]

録音した 音の 再生の 速さ。2 で 2倍 速く 高く、-1 で 逆再生。

s("bd").speed(2)

レコードや テープを 速く まわすと 音が 高く なる のと 同じ しくみ。

clip ノーマル

ブロック: [音の長さ clip ▼] [.3]

音の 長さ。1 で 次の 音まで、0.3 で 短く 切る。

note("c4 e4").s("square").clip(.3)

英語で「切りとる」。

vowel ノーマル

ブロック: [母音 vowel ▼] [a]

音を「あ・い・う・え・お」の ような 声の 響きに する。

s("sawtooth").vowel("<a e i o>")

英語で「母音」。人の 声の 母音を つくる 響き(フォルマント)を まねる フィルター。

unison / detune / spread ノーマル

ブロック: [ユニゾン ▼] [7]

supersaw の 厚み。unison は かさねる 本数、detune は 高さの ずれ、spread は 左右の 広がり。

note("a3").s("supersaw").unison(7).detune(.4).spread(.8)

unison(ユニゾン)は ラテン語で「1つの 音」。何人もが 同じ 音を 歌う ことだよ。detune は「チューニングを はずす」。

fm ノーマル

ブロック: [金属っぽさ fm ▼] [2]

音を 金属っぽく、ベルや エレピの ような 音に する(FM合成)。

note("c4").s("sine").fm(2)

frequency modulation(周波数変調。FM ラジオと 同じ ことば)。1967年に スタンフォード大学の ジョン・チャウニングさんが 発見し、1983年の ヤマハ DX7 で 世界中に 広まった。

クラブミュージックの わざ

orbit ノーマル

ブロック: [オービット ▼] [2]

音が 通る 通り道(1〜8)を きめる。ひびきや やまびこ、duck は 通り道ごとに かかる。

note("a1*8").s("sawtooth").orbit(2)

英語で「軌道」。TidalCycles の 音源 SuperDirt で、トラックごとの 効果が まざらない ように 分ける しくみの 名前だよ。

duck / duckattack / duckdepth ノーマル

ブロック: [ダック ▼] [2]

キックが 鳴るたびに、ほかの 通り道(orbit)の 音を しぼませる。音が 息を する ように「ポンプ」する。

s("bd*4").duck("2:3").duckattack(.2).duckdepth(.8)

英語で「ひょいと 頭を 下げる」。ラジオで 話す ときに 音楽を 小さく する わざ「ダッキング」から。クラブミュージックでは「サイドチェイン」「ポンピング」とも いい、2000年代の フレンチハウスや EDM で 流行した。

acidenv マスター

ブロック: アシッド [.6]

ノコギリ波と フィルターを セットに して、アシッドの「ビヨビヨ」した 音に する。

(ブロックだけ。書き出すと s・lpf・lpenv・lps・lpd・lpq が ならぶ)

1981年の ローランド TB-303 は、ベースの かわりの 機械として 売れなかった。でも 1987年、シカゴの Phuture が つまみを ぐるぐる 回して つくった「Acid Tracks」から「アシッドハウス」が 生まれた。名前は Switch Angel さんの strudel-scripts の 関数 acidenv から もらったよ。

trancegate マスター

ブロック: トランスゲート [.8] [45] [1]

長い 和音を 細かく きざんで、トランスの「タタタタ」と いう 音に する。

(ブロックだけ。書き出すと struct・fillGaps・clip に なる)

トランスという 音楽で 1990年代の おわりごろから よく つかわれる「ゲート」(音を 開け閉めする 門)の わざ。名前は Switch Angel さんの strudel-scripts の 関数 trancegate から。

音を 見る

scope ビギナー

ブロック: [スコープ] を表示する

音の 波の 形を 線で 見せる。

s("sawtooth")._scope()

oscilloscope(オシロスコープ)の 略。電気の 波を 見る 測定器。

pianoroll ビギナー

ブロック: [ピアノロール] を表示する

音の 高さと 長さを、横に 流れる 帯で 見せる。

note("c4 e4 g4")._pianoroll()

1900年ごろの 自動ピアノは、穴の あいた 紙の ロール(巻物)で 曲を 演奏した。その 見た目が もとに なった 名前。

spectrum ビギナー

ブロック: [スペクトル] を表示する

低い 音から 高い 音まで、どれが どれくらい 鳴っているかを 見せる。

s("bd hh")._spectrum()

英語で「スペクトル」。光を プリズムに 通すと 虹色に 分かれる ように、音を 高さごとに 分けて 見る。

punchcard ビギナー

ブロック: [パンチカード] を表示する

ピアノロールを 穴の あいた カードの ように 見せる。

note("c4 e4 g4")._punchcard()

パンチカードは 穴の 位置で 情報を あらわす カード。1800年代の はじめ、ジャカールの 織機が 布の 模様を あやつる のに つかい、のちに コンピューターにも つかわれた。

音階・和音の 名前

major / minor ノーマル

ブロック: 音階 scale [C4] [minor]

major は 明るい 音階(長調)、minor は 暗い 音階(短調)。

n("0 2 4").scale("C4:minor")

英語で major =「大きい」、minor =「小さい」。ドと ミの 間(3度)が 大きいか 小さいかで 名前が ついた。

major:pentatonic / minor:pentatonic ノーマル

ブロック: 音階 scale [C4] [major:pentatonic]

5つの 音だけの 音階。どう ならべても きれいに 聞こえる。

n("0 1 2 3 4").scale("C4:major:pentatonic")

ギリシャ語の penta(5)+ tonic(音)。日本の「ヨナ抜き音階」も その 仲間(4番目と 7番目を ぬく)。

blues / dorian / chromatic ノーマル

ブロック: 音階 scale [C4] [blues]

blues は ブルースの 音階、dorian は ジャズや ケルト音楽で 好まれる 音階、chromatic は 半音を ぜんぶ ならべた 音階。

n("0 1 2 3").scale("C4:dorian")

dorian は 古代ギリシャの ドーリア人から 名前を とった 音階で、中世の 教会音楽を へて 今に つたわる。chromatic は ギリシャ語の chroma(色)から。
