0じゅんび:拡張機能を 入れる

ステップの 作品から はじめるときは、拡張機能は もう 入っているので この じゅんびは いらないよ。

じぶんで 1から つくるときは、このボタンが いちばん かんたん。拡張機能が 入った 新規プロジェクトが ひらくよ。

新規プロジェクト

いま つかっている 作品に 入れるときは、つぎの じゅんばんで 読みこんでね。

  1. Xcratch エディターを ひらく。
  2. 左下の「拡張機能を追加」ボタンを おす。
  3. いちばん はじめの「拡張機能を読み込む」を えらぶ。
  4. つぎの URL を 入れて「OK」を おす。 https://0x48lab.github.io/xcx-strudel/dist/strudel.mjs

左に「ストゥルーデル」が ふえたら せいこう。うずまきの マークが ついた みどりの ブロックが ならぶよ。

さいしょは「ビギナー」レベルの ブロックだけが 出ているよ。いちばん 上の ブロックで「ノーマル」「マスター」に すると、ブロックが ふえるよ。

ブロックを ひらがなに したいときは、上の「設定」→「言語」で「にほんご」を えらんでね。

音が 出ないときは、ステージの みどりの はたを もう一度 おしてみてね。ブラウザは、画面を さわるまで 音を 出さない きまりが あるんだ。

1音を 1つ 鳴らそう

「トラック [ ] で鳴らす」が いちばん 大事な ブロック。「C」の かたちに 口が あいていて、中に 入れた ブロックが 1つの トラックの 音に なるよ。ここでは 中に「s」(sound。音の しゅるいを えらぶ)ブロックが 入っているね。みどりの はたを おすと、bd(バスドラム)が「ドン、ドン…」と ずっと くりかえし 鳴るよ。止めるときは 赤い ボタン。

「s」の ▼ を おすと、ほかの 音を えらべるよ。ドラムの 音(sd スネア、hh ハイハット、cp 手拍子 など)と、シンセサイザーの 音(sine・square・sawtooth・triangle・supersaw)と、休みの ~ が あるよ。名前は ぜんぶ Strudel と 同じ だよ。

やってみよう
  • sd や cp に かえてみよう。鳴らしたまま かえても いいよ。
  • 「s」を トラックから 外して、かわりに「note」(音の 高さ)ブロックを 入れてみよう。c4 が ド、d4 が レ だよ。
このステップを ひらく

2順番に ならべよう

トラックの 中に「seq」(順番に ならべる)ブロックを 入れると、4つの 音が じゅんばんに 鳴るよ。「ドン・ッ・タン・ッ」の ビートの できあがり。「seq」の ▼ では、ドラムの 音と ドレミの 音と 休みの ~ を えらべるよ。

サイクルって なに?

Strudel では、くりかえしの ひとまとまりを「サイクル」と よぶよ。「seq」に 入れた 音は、1サイクルの 中に ぴったり おさまるように ならぶ。だから 4つなら 4等分、8つなら 8等分に なるよ。はやさを かえたいときは「テンポを〜BPMにする」を つかってね。

トラックの 名前(ここでは「ドラム」)は、じぶんで すきに つけていいよ。

やってみよう
  • ~ を hh に かえると、どう かわるかな?
  • テンポを 80 や 140 に してみよう。
このステップを ひらく

3トラックを かさねよう

トラックの ブロックを もう1つ つなげて、ちがう トラック名を つけると、2つの 音が いっしょに 鳴るよ。バンドで 楽器が ふえていく かんじだね。

「fast」(はやく する)は、1サイクルの 中で 同じ 音を なんども 鳴らす ブロック。「s hh」の 下に つむと、hh を 8回 きざんで、ぐっと ノリが よくなるよ。

トラックの 中の ブロックは、上から じゅんばんに 読むよ。さいしょに 音(ここでは hh)を きめて、その 下に「どう かえるか」(ここでは fast 8)を つんでいくんだ。

同じ トラック名で もう一度 鳴らすと、前の 音と 入れかわるよ。これは つぎの ステップ5で つかうよ。

やってみよう
  • 「fast」の 数を 16 や 3 に してみよう。
  • 「s hh」の かわりに「stack」(同時に かさねる)ブロックを 入れて、bd と cr(シンバル)を いっしょに 鳴らしてみよう。
このステップを ひらく

4メロディを つくろう

3つめの トラック「メロディ」を ふやしたよ。上から 読んでいこう。

  1. 「seq c4 e4 g4 c5」で、ド ミ ソ 高いド の フレーズを つくる。
  2. その 下の「s」で、音の しゅるい(ねいろ)を えらぶ。triangle(すっきりした 音)、sawtooth(ギザギザの 音)、square(ピコピコ音)、sine(やわらかい 音)などが あるよ。

ステップ1では「s」が 音そのものを きめたけど、音の 高さの 下に つむと、その 高さを どの 音で 鳴らすかを きめるんだ。

やってみよう
  • 「s」の 音色を sawtooth や square に かえてみよう。
  • c4 や e4 を かえて、じぶんの メロディを つくろう。
  • 「seq」の かわりに「cat」(1サイクルごとに 交互に 鳴らす)を 入れてみよう。c4 と g4 なら、ド・ソ・ド・ソ… と 1サイクルずつ かわるよ。
このステップを ひらく

5キーで 曲を かえよう

演奏しながら 曲を かえるのが、Strudel の いちばん 楽しい ところ。これを「ライブコーディング」と いうよ。

  • スペースキー:「ドラム」トラックに ちがう リズムを 鳴らす。同じ トラック名なので、前の リズムと 入れかわるよ。
  • s キー:「トラック〜を止める」で ハイハットだけ 止める。
  • 0 キー:「すべてのトラックを止める」。

入れかわるのは、つぎの サイクルの はじめ。だから いつ キーを おしても、リズムが ずれないよ。

キーを つかうときは、さいしょに ステージを 1回 クリックしてね。

やってみよう
  • キーを ふやして、リズムを 3しゅるい 切りかえられるように しよう。
このステップを ひらく

6音を 目で 見よう

「〜を表示する」で、鳴っている 音を ステージに 絵で 出せるよ。▼ で スコープ(scope)・ピアノロール(pianoroll)・スペクトル(spectrum)・パンチカード(punchcard) を えらべるよ。

ピアノロール(pianoroll)は、まんなかの たての 線の ところが「いま」。上に あるほど 高い 音だよ。音の 絵は スプライトの うしろに 出るので、ねこも ちゃんと 見えるよ。

このステップを ひらく

7ねこを おどらせよう

音に あわせて スプライトを うごかす ブロックが あるよ。

  • 「拍がきたとき」:はくごとに 動く。コスチュームを かえると、ねこが 足ぶみするよ。
  • 「〜が鳴ったとき」:えらんだ ドラムが 鳴るたびに 動く。bd で ジャンプ、sd で 色を かえる、なども できるよ。

いつもの Scratch の ブロックと 組みあわせられるのが、この 拡張機能の いいところ。

やってみよう
  • sd が 鳴ったら「色の効果を 25 ずつ変える」に してみよう。
  • 「拍」や「サイクル」の 値を つかって、ねこを 動かしてみよう。
このステップを ひらく

8ノーマルレベル:ミニ記法・効果・音階

いちばん 上の ブロックを「ノーマル」に すると、ブロックが ふえるよ。▼ で えらぶ「音 s [bd ▼]」「音の高さ note [c4 ▼]」は、文字を 書ける「音 s [ ]」「音の高さ note [ ]」に 入れかわるよ。

ミニ記法

文字を 書く「s」ブロックと「note」(音の 高さを 書く)ブロックには、Strudel と 同じ ミニ記法で 音を ならべて 書けるよ。この 作品の ドラムは bd*2 [~ sd] <hh oh> sd、ベースは <c2 a1 f1 g1>*2 だよ(ブロックの 中では 長い 文字は「…」で 省略されて 見えるよ)。

書きかたいみれい
bd sdスペースで くぎると 順番に 鳴るbd hh sd hh
~休みbd ~ sd ~
*2その音を 2回に ふやすhh*8
[ ]1つ分の 時間に つめこむbd [sd sd]
< >サイクルごとに 1つずつ こうたい<bd cp>
,同時に 鳴らすbd*4, hh*8

効果と 音階

  • 効果の ブロック「[ひくい音だけ通す lpf ▼] [600]」:▼ で 効果を えらんで、となりに 値を 書くよ。lpf(高い 音を けずって こもらせる)、room(ひびき)、delay(やまびこ) など。ベースは「s sawtooth」の 下に「lpf 600」を つんで、やわらかい 音に しているよ。
  • 「n」と「scale」(音階):「n」で 音階の 何番目の 音かを 数字で 書いて、その 下の「scale」で 音階を えらぶ。major:pentatonic(ヨナ抜き長音階)なら、どの 数字でも きれいに 聞こえるよ。「s」で えらべる piano は、本物の ピアノの 音を 自動で 読みこむよ。
このステップを ひらく

9リストと リズムで 曲を 書こう

コード進行や メロディが 長くなると、ミニ記法の 1行は とても 読みにくく なるよ。そこで Scratch の「リスト」に 1小節ずつ 書いて、ブロックで つなげよう。リストなら 1行 = 1小節で、どこに 何が あるか ひと目で わかるよ。ここから 先の ステップは、ぜんぶ リストで 曲を 書いていくよ。

このステップを ひらく

1. リストを つくる

「変数」の カテゴリーで「リストを作る」を おして、名前を つけるよ。この 作品には「コード」「ベース」「メロディ」「リズム」「ドラム」の 5つの リストが もう 入っているよ。

リストの 名前の よこの チェックを 入れると、ステージに リストが 出るよ。項目を クリックすると 書きかえられて、下の「+」で 項目を ふやせるよ。

1つの 項目には、1小節ぶんの ミニ記法を 書くよ。和音は [f3,a3,c4] のように、いっしょに 鳴らす 音を , で ならべて [ ] で かこむよ。

この リストの 和音は、ファ・ソ・ミ・ラ の 和音を じゅんばんに 鳴らす「王道進行」。J-POP で とても よく つかわれる 進行だよ。

2. リストを 鳴らす

「リスト [ ] の中身を [ ] ならべる」ブロックを、「note」ブロックの 文字の ところに はめこむよ。リストの 項目が つながって、1つの ミニ記法に なるんだ。

▼ で えらぶ ならべかたできる ミニ記法つかいどころ
1サイクルに1つずつ<[項目1] [項目2] …>1項目 = 1小節。リスト「コード」「ベース」「メロディ」
1サイクルの中に順番に[項目1] [項目2] …1項目 = 1拍。リスト「リズム」
ぜんぶ同時に[項目1], [項目2], …1項目 = 1つの 楽器。リスト「ドラム」

1 キーを おすと、和音が 1小節ずつ「ジャーン」と のびて 鳴るよ。キーを おす 前に、ステージの リストの 外を クリックしてね(リストの 中を クリックすると、キーが リストの 書きかえに なっちゃうよ)。

3. リズムで 刻む

「note」の 下に つんだ「struct」(リズムの かたちで 刻む)ブロックは、x の ところだけ 音を 鳴らすよ。~ は 休み。和音は そのままで、リズムだけ つけられるんだ。

リズムも リストに 入っているよ。リスト「リズム」の 項目は x ~、~ x、x x、~ x の 4つ。「1サイクルの中に順番に」ならべると、1項目が 1拍に なるよ。1拍を 2つに 分けて「タン・ウン」「ウン・タン」と 書いているんだ。2 キーで ピアノが 入れかわって、はずむように なるよ。

拍1234
リスト「リズム」x ~~ xx x~ x

いじってみよう:4つの 項目を ぜんぶ x に すると 4分音符、~ x に すると 裏打ちに なるよ。和音は 同じでも、曲の かんじが がらっと かわるよ。

Strudel では

note("<[[f3,a3,c4]] [[g3,b3,d4]] [[e3,g3,b3]] [[a3,c4,e4]]>")
  .struct("[x ~] [~ x] [x x] [~ x]").s("piano")
s("[bd [~ bd] ~ ~], [~ ~ sd ~], [hh*8]")

4. ベース・メロディ・ドラムを かさねる

ベースと メロディも、それぞれ リストに 1小節ずつ 入っているよ。3・4・5 キーで かさねていこう。0 キーで ぜんぶ 止まるよ。

ドラムは「ぜんぶ同時に」ならべるよ。リスト「ドラム」は 1項目が 1つの 楽器の 行。ドラムマシンの 画面のように、楽器ごとに リズムを 書いて かさねるんだ。

やってみよう

  • リスト「メロディ」に 項目を 4つ たして、8小節の メロディに しよう(コードと ベースは 4小節で くりかえすよ)。

10じぶんの 声で ビートを つくろう

Scratch で 録音した 声や、Scratch に はじめから 入っている 音も、Strudel の 楽器に できるよ。じぶんの 声が ビートに なったら、きっと 楽しいよ。

このステップを ひらく

1. 声を 録音する

  1. 上の「音」タブを ひらく。
  2. 左下の「音を選ぶ」ボタンに マウスを のせて、出てきた マイクの ボタン(録音する)を おす。
  3. ブラウザに「マイクを つかって いいですか」と きかれたら「許可」を おす。
  4. 赤い まるの「録音する」を おして 声を 入れ、おわったら 止める。「再生」で 聞いて、よければ「保存」を おす。

「ドン」「パッ」「チー」のように、みじかい 声が つかいやすいよ。録音した 音は「録音1」のような 名前で、音の 一覧に ふえるよ。この 作品には、さいしょから ねこの「Meow」が 入っているよ。

2. 声を 鳴らす

トラックの 中に「スプライトの音 [ ]」ブロックを 入れて、▼ で 鳴らしたい 音を えらぶよ。録音した 声も ここに 出てくるよ。「s」と 同じように、トラックの いちばん 上に 入れる 音の ブロックだよ。

3. くりかえして 短く する

「fast 4」で 1サイクルに 4回。声が 長くて かさなるときは、効果の「clip」(音の 長さ)で 短く 切ろう。

4. 高さを かえる

効果の「speed」(再生の 速さ)で 声の 高さが かわるよ。1 1.5 2 -1 と 書くと、4回の 声が じゅんばんに この 高さに なるよ。

speedどうなる?
1そのままの 声
21オクターブ 高く、はやく なる
0.51オクターブ 低く、ゆっくり なる
-1さかさまに 鳴る(逆再生)

5. ひびきを つける

4 キーは、1小節ごとに 高さを かえて「room」(ひびき)を つけた 声。0 キーで ぜんぶ 止まるよ。

やってみよう
  • じぶんの 声を 録音して、ぜんぶの「スプライトの音」の ▼ を その 声に かえてみよう。
  • 「ドン」「パッ」を べつべつに 録音して、2つの トラックで かさねてみよう。「パッ」の トラックは「fast 2」と 効果の「speed」で、ずらして 鳴らすと おもしろいよ。
  • マスターレベルの「チョップ」(chop。音を こまかく 切る)を つかうと、長い 声を こまかく 切って 刻めるよ。

録音した 声は ブラウザの 中だけに あるので、strudel.cc に もっていくと その 音だけは 鳴らないよ。作品を 保存すると、声も いっしょに 保存されるよ。

このステップを ひらく

11ジャズ・ソウルの 和音

おしゃれな J-POP で よく 聞く、ジャズや ソウルの 和音を つかった オリジナル曲だよ(サンプル「ソウルな ピアノ ポップ」と 同じ 曲)。和音・ベース・メロディは リストに 1小節ずつ 入っているよ。

このステップを ひらく

和音の ひみつ

コード進行は | FM7 | Em7 A7 | Dm7 G7 | Cmaj9 C9 | FM7 | Fm6 | Em7 E♭dim7 | Dm7 G7sus4 |。ステップ9の 王道進行(F → G → Em → Am)と くらべてみよう。

3Dm7 → G7(ツーファイブ)ジャズの きほん。つぎの 和音に 帰りたくなる 力が 生まれるよ
6Fm6明るい F が、暗い Fm に かわる。ちょっぴり ほろにが
7Em7 → E♭dim7 → Dm7ベースが ミ → ミ♭ → レ と 半音ずつ 下がっていく

ピアノは 根音(ルート)を はぶいているよ。根音は ベースが ひくので、ピアノは ひびきの 色を つける 音だけを ひいているんだ。

ベースと メロディの リストも、1拍を 3つに 分けて 書いているよ。

やってみよう
  • リスト「コード」の 6番目 [f3,ab3,c4,d4](Fm6)を [f3,a3,c4,e4](FM7)に かえて、聞きくらべよう。ほろにがさが きえるよ。

12マスターレベル:アシッドと トランスゲート

「マスター」に すると、クラブミュージックで つかう わざが つかえるよ。

  • 「ユークリッド」(euclid。ユークリッドリズムで ちらす):「s bd」の 下に つんだ euclid 5 8 で 8拍に 5回、のように 音を できるだけ 均等に ちらす。世界中の 民族音楽に 出てくる リズムだよ。
  • 「bank」(ドラムマシンを えらぶ):RolandTR909 などの 有名な ドラムマシンの 音に する。
  • 「range」の ブロック(ゆれる 値):sine range 0 1 slow 2 のように、波の かたち(sine なめらか、saw だんだん 上がる など)と はんいと 速さを えらぶ。数字の かわりに 入れると、値が 波のように ゆれる。ここでは 効果の pan(左右の いち)の 値に 入れて、ハイハットが 左右に ゆれるよ。丸い ブロックは、こういう「値」に 入れる ブロックだよ。
  • 「アシッド」(acidenv。アシッドな 音に する):ビヨビヨした ベースの 音(TB-303 ふう)。名前は Switch Angel さんの strudel-scripts に ある acidenv 関数から もらったよ。
  • 「和音」:A3 の minor のように、根音と 和音の しゅるいを えらんで 和音を 鳴らす。
  • 「トランスゲート」(trancegate。細かく 刻む):のばした 和音を 細かく 刻む。trancegate 密度 seed 長さ の 2つめの 数字(seed)を かえると、刻みかたが かわるよ。名前は Switch Angel さんの trancegate 関数から もらったよ。
やってみよう
  • 「ユークリッド」の 1つめの 数を 3 や 7 に してみよう。
  • 「トランスゲート」の seed を 0〜20 で かえて、すきな 刻みを さがそう。
このステップを ひらく サンプル作品で あそぶ

コラムブロックを Strudel の コードに しよう

ここまで くんできた ブロックは、ぜんぶ 本物の Strudel の コードに できるよ。応用編では、ブロックの となりに「Strudel では」として コードも のせているので、さきに 読みかたを 知っておこう。

  • 「全部のトラックのStrudelコード」:鳴らした トラックを コードに して かえすよ(止めた あとも のこるよ)。ブロックを クリックするだけでも 見られるよ。
  • 「全部のトラックを strudel.cc で開く」:strudel.cc が ひらいて、同じ 曲が コードで 鳴るよ。

ステップ12の 作品で、はたを おしてから c キー、o キーを おしてみよう。

ブロックと コードの 対応

ブロックStrudel の コード
トラック 〜 で鳴らす(C の かたち)$: …(1行に 1トラック)

関数って なに?

関数は、パターンを 受け取って、かえた パターンを かえす しかけだよ。コードの . の あとの 名前が 関数の 名前、() の 中が 関数に わたす 値(引数)。

note("c3 e3 g3").transpose(12)   // transpose 関数に 12 を わたす → 1オクターブ 上の パターン
note("c3 e3 g3").lpf(600)        // lpf 関数に 600 を わたす → こもった 音の パターン

つなげて 書くと、左から じゅんばんに かかるよ。トラックの 中に ブロックを 上から つむのと 同じだね。

ブロックは 上から 読む

ブロックには Strudel の 関数の 名前が 書いてあるよ(カタカナの ブロックは、その 読みかた)。トラックの 中の ブロックを 上から じゅんばんに 読むと、そのまま コードに なるよ。ステップ13の リードの トラックは、上から n・scale・s supersaw・スーパーインポーズ 1オクターブ上・ユニゾン 7・room .8 と ならんでいるね。コードでは n(…).scale(…).s("supersaw").superimpose(…).unison(7).room(.8) に なるよ。

いちばん 上の ブロック(s・note・n・seq など)で 音を つくって、その 下の ブロックが じゅんばんに 音を かえていくんだ。いちばん 上より 下に ある「s」や「note」は、.s(…) のように 音色や 高さを かえる ブロックに なるよ。

関数を わたす 関数

マスターレベルの sometimes・every・jux・off・superimpose は、引数として「関数」を もらう 関数だよ(高階関数と いうよ)。▼で えらぶ rev や transpose 12 も 1つ 1つが 関数。ブロックが「いつ・どこに かけるか」、▼が「何を するか」を きめるんだ。

ブロックStrudel の コードすること
sometimes.sometimes(x => x.transpose(12))ときどき(半分くらいの 音に)関数を かける
every.every(4, x => x.rev())4サイクルに 1回 関数を かける
jux.jux(x => x.rev())左右に 分けて、右だけに 関数を かける(juxtapose = ならべて おく)
off.off(0.125, x => x.transpose(7))少し おくらせて、関数を かけた ものを 重ねる
superimpose.superimpose(x => x.transpose(12))関数を かけた ものを 重ねる

x => x.transpose(12) は「x を もらって、x を 1オクターブ 上げた ものを かえす」と 読むよ。名前の ない、その場で つくる 関数なんだ。

Scratch の「ブロックを作る」で つくる じぶんの ブロックも、関数の なかま だよ。Strudel を つかう ときは、ブロックの 名前(seq、lpf、sometimes、transpose など)が そのまま コードに なるので、名前で おぼえておこう。

ブロックの 名前 1つ 1つの いみと、名前の ゆらい・れきしは「関数じてん」に まとめて あるよ。

strudel.cc の つかいかた

  • コードを 書きかえたら Ctrl+Enter で 鳴らしなおす。Ctrl+. で 止まるよ。
  • 数字は 1つずつ かえて、そのたびに 聞いてみよう。
  • トラックの 行の さいごに .hush() を つけると、その トラックだけ 消せるよ。
  • 「トランスゲート」(trancegate)は Strudel に はじめから ある 関数では ないので、コードでは 同じ 動きを する 関数(fillGaps)が いっしょに 書き出されるよ。スプライトの 音は strudel.cc では 鳴らないよ。
ステップ12の 作品を ひらく

13応用編:EDM・トランスの 音づくり

クラブで 流れる EDM や トランスは、いくつかの「部品」を かさねて できているよ。キーを 1つずつ おして 部品を ふやしながら、それぞれの 音が どんな やくわりか、耳で たしかめよう。テンポは 140 BPM だよ。

キー部品キー部品
1キック5リード
2裏打ちベース6ビルドアップ(スネア+ライザー)
3トランスゲートのパッドスペースドロップ(ビルドアップを 止める)
4アルペジオのプラック7ポンピング(1 で もとに もどる)

0 キーで ぜんぶ 止まるよ。どの 部品も、つぎの サイクルの はじめから 鳴りはじめるよ。

音の 中身は、ステップ9と 同じように リストに 1小節ずつ 入っているよ。

リスト中身(1小節ずつ)つかう 部品
コード[a3,c4,e4,a4] [f3,a3,c4,f4] [c4,e4,g4,c5] [g3,b3,d4,g4]パッドと プラック(同じ リストを 2つの 部品で つかう)
ベース[~ a1]*4 [~ f1]*4 [~ c2]*4 [~ g1]*4裏打ちベース
リード[7 ~ 9 11] [12 11 ~ 9] など 4小節リード(音階の 番号)

リスト「コード」を 書きかえると、パッドも プラックも いっしょに かわるよ。

応用編を ひらく

1. キック:4つ打ち

1小節に 4回「ドン・ドン・ドン・ドン」。これが ダンスミュージックの 心臓だよ。TR-909 は、ハウスや テクノで 使われてきた 有名な ドラムマシンの 音。

Strudel では

s("bd*4").bank("RolandTR909")

2. 裏打ちベース

リスト「ベース」の [~ a1]*4 は「休み・ラ」を 4回。キックの あいだ(裏拍)だけで 鳴るので、キックと ぶつからずに「ドッ・ベッ・ドッ・ベッ」と はずむよ。< > で 1小節ごとに ラ→ファ→ド→ソ と かわる。「lpf 500」で 高い 音を けずって、低音だけに しているよ。さいごの「orbit 2」(音の 通り道)は 7. ポンピングで せつめいするよ。

Strudel では

note("<[~ a1]*4 [~ f1]*4 [~ c2]*4 [~ g1]*4>").s("sawtooth").lpf(500).orbit(2)

いじってみよう:リスト「ベース」の [~ a1]*4 を [~ a1 a1 a1]*4 に すると、トランスで よく 聞く「転がる ベース」に なるよ。

3. トランスゲートの パッド

リスト「コード」の 和音を、supersaw(ギザギザ音を 何本も 重ねた 分厚い 音)で のばし、「トランスゲート」で 細かく 刻むよ。「room」で 広い ホールに いるような 音に。

Strudel では

note("<[a3,c4,e4,a4] [f3,a3,c4,f4] [c4,e4,g4,c5] [g3,b3,d4,g4]>").s("supersaw")
  .trancegate(.8, 45, 1).room(.6).orbit(2)

「トランスゲート」(trancegate)は この 拡張機能が 用意した ブロックだよ(名前は Switch Angel さんの trancegate 関数から もらったよ)。strudel.cc で 開くと、同じ 動きを する Strudel の 関数(struct と fillGaps)に 書きかわるよ。

4. アルペジオの プラック

パッドと 同じ リスト「コード」の 和音を「ばらして」1つずつ 鳴らすのが アルペジオ。ブロックは「アルペジオ」(arp。和音を ばらして 鳴らす)だよ。「clip .3」で 短く 切ると、弦を はじいたような「ポン」という 音(プラック)に なるよ。「ディレイ」で 音が おくれて くりかえされ、きらきら 広がるよ。

Strudel では

note("<[a3,c4,e4,a4] [f3,a3,c4,f4] [c4,e4,g4,c5] [g3,b3,d4,g4]>")
  .arp("0 1 2 3 2 1 2 3").s("square").clip(.3).delay(.4).orbit(2)

5. 分厚い リード

メロディを 目立たせる わざが 3つ 入っているよ。

  • ユニゾン 7(unison。厚み):ギザギザ音を 7本、少しずつ 音の 高さを ずらして 重ねる。人が 大ぜいで 歌うと 声が 太く 聞こえるのと 同じ しくみ。
  • スーパーインポーズ [1オクターブ上](superimpose。重ねる):同じ メロディを 1オクターブ 高い 音でも 鳴らして、きらっと させる。▼の 中身(transpose 12)を かけた ものを、元の メロディに 重ねる 関数だよ。
  • room .8:大きな ひびきで、遠くまで 広がる 感じを 出す。

Strudel では

n("<[7 ~ 9 11] [12 11 ~ 9] [11 ~ 9 7] [8 ~ 9 6]>*2").scale("A3:minor")
  .s("supersaw").superimpose(x => x.transpose(12)).unison(7).room(.8).orbit(2)

いじってみよう:unison を 1 と 7 で 聞きくらべよう。「分厚い」の いみが すぐ わかるよ。効果の detune(音の ずれ)と spread(左右の 広がり)も ためしてね。

6. ビルドアップと ドロップ

サビの 前に 気分を もりあげる 部分を「ビルドアップ」と いうよ。

  • スネア:リスト「ビルドアップ」の sd*4 → sd*8 → sd*16 → sd*32 で、1小節ごとに 2倍ずつ 細かくなる。saw(だんだん 上がって、ストンと もどる 波)の「range」ブロックを gain(音の 大きさ)に 入れて、音も 大きく なっていくよ。
  • ライザー:white(ホワイトノイズ)は ザーッという 音。hpf(低い 音を けずって シャカシャカに する)の 値を 300 から 9000 まで 上げると、低い 音が けずられて「シューーッ」と 上がっていく 音に なるよ。

もりあがったところで スペースキー! ビルドアップが 止まって、のこりの 部品が どーんと 鳴る。これが「ドロップ」。ゆれる 値は slow 4 で 4サイクルに 1まわり するので、上がりきった ところで おすと 気持ちいいよ。

Strudel では

s("<sd*4 sd*8 sd*16 sd*32>").bank("RolandTR909").gain(saw.range(.3, 1).slow(4))
s("white*16").hpf(saw.range(300, 9000).slow(4)).gain(saw.range(0, .4).slow(4))

7. ポンピング

EDM らしさの いちばんの ひみつ。キックが 鳴るたびに、ほかの トラックの 音を 一しゅん 小さくして、すぐ もどすよ。音全体が「ワウ・ワウ」と 息を するように うねるんだ。プロは「サイドチェイン」と よんでいるよ。

Strudel の 音は「orbit」(オービット。音の 通り道)を 通って 流れるよ。何も しないと みんな orbit 1。この 作品では、ベース・パッド・プラック・リードに 効果の「オービット 2」を つけて、orbit 2 の 通り道に 分けておいたんだ。キックは orbit 1 の まま。そして キックに、つぎの 3つの 効果を つけるよ。

  • ダック 2(しぼませる。duck は 英語で「ひょいと 頭を 下げる」):キックが 鳴るたびに、orbit 2 の 音を しぼませる。2:3:4 のように : で つなぐと、いくつもの orbit を いっしょに しぼませられるよ。
  • duckattack .2:しぼんだ 音が もとの 大きさに もどるまでの 時間(秒)。
  • duckdepth .85:どれくらい しぼませるか。0(しぼまない)〜 1(いちばん しぼむ)だよ。

同じ「キック」トラックなので、7 を おすと ふつうの キックと 入れかわる。1 と 7 を 何回か おして 聞きくらべてね。

Strudel では

s("bd*4").bank("RolandTR909").duck("2").duckattack(".2").duckdepth(".85")

ベース・パッド・プラック・リードの コードの さいごに .orbit(2) が ついているのは、この ポンピングの ためだよ。orbit 2 に いない 音(キックや ビルドアップ)は しぼまないよ。

つぎは コードで

部品を ぜんぶ 鳴らしてから「全部のトラックを strudel.cc で開く」ブロック(コラム)を つかうと、この 曲が そのまま Strudel の コードに なるよ。コードの 数字を 1つずつ かえて、Ctrl+Enter で 鳴らしてみよう。部品の 行の さいごに .hush() を つけると、その 部品だけ 消せるよ。

応用編を ひらく strudel.cc
